# Домашняя страница

Этот проект минималистичная домашняя страница, которая будет размещена на GitHub Pages.

Весь сайт должен состоять из простых HTML-страниц. CSS должен быть прямо в этом файле с ней.

У сайта должны быть темная и светлая темы (по умолчанию тёмная), а также английская и русская локализации (по умолчанию английская).

На сайте должна быть информация о том, что меня зовут Евгений Трифонов, Должны быть ссылки на отдельные мои мини-роекты (вне сайта), посты (публикуются на самом сайте отдельными HTML-страницами), и мои контакты (почта eugene.triphonov@gmail.com, Telegram @expectfun).

Для первого поста продублируй этот: https://overconfidence.bearblog.dev/jagged-intelligence/
