# City

City is a small interactive web mini-site built from linked scene pages.
Users move through a cyberpunk-style environment via clickable hotspots, while a shell page provides navigation, music, and transitions.

## What it includes

- Scene-based world in `places/` (entry, streets, station, library, hotel, etc.)
- Tool pages in `tools/` (flow, charcount, quiz, AI news, mini-games)
- Local media assets in `pics/` and `audio/`
- Shared scripts in `js/`
- Supporting content in `posts/`, `data/`, and `docs/`

## Entry point

Open `index.html` inside the `city/` folder.

## Notes

- This is a static HTML/CSS/JS project (no build step).
- Some features intentionally rely on external web resources (CDNs and embedded tools).
